# الحزمة الموحدة لأدوات الباحث 1.3.1

## البحث في المصادر

يعمل البحث في الجامع والمكتبة الشاملة عبر خادمي MCP السحابيين فقط، من خلال مزودي الذكاء الاصطناعي Groq وGemini. لا يتصل هذا المسار بأي خدمة محلية، ولا يحتاج إلى مضيف MCP محلي أو جسر أو منفذ loopback.

## مزود Duck.ai العام

يظل خيار Duck.ai في إعدادات الذكاء الاصطناعي العامة منفصلًا عن بحث المصادر؛ فهو يستخدم واجهة Duck2API المحلية لمهام Word الأخرى. يحافظ هذا الإصدار على ملف Duck2API الموجود، ويستبدل المشغّل القديم بمشغّل بسيط لنقطة API العامة على 127.0.0.1:18080. ولا يشغّل MCP أو أدوات البحث المحلية.

إذا لم يكن محرك Duck2API مثبتًا مسبقًا على الجهاز، فلن ينشئ المثبّت حزمة محلية جديدة له؛ ويمكن استخدام مزودات السحابة المتاحة في إعدادات الأداة.

## التغييرات عند التثبيت

- إزالة مضيف MCP المحلي ومجلده وجسر DuckAI-MCP ووكيل DuckAgent القديم.
- إزالة مهمة التشغيل القديمة والمشغّل الذي كان يدير MCP المحلي.
- الحفاظ على مجلد DuckAI ومحرك duck2api-main.exe المستخدم في المهام العامة، مع تسجيل مهمة واحدة خفيفة لتشغيل نقطة API العامة عند تسجيل الدخول.
- الحفاظ على كتالوج Office ونسخ Manifest الاحتياطية وسجلات التثبيت.
- لا يغيّر المثبّت ملفات التطوير في C:\Word AI Assistant v2.

## التثبيت

1. أغلق Microsoft Word بالكامل.
2. شغّل ResearchTools-Setup.exe من حساب Windows المعتاد.
3. وافق على طلب صلاحية إنشاء مشاركة مجلد الإضافات إذا احتاج الجهاز إلى كتالوج Word جديد.
4. بعد اكتمال التثبيت، افتح Word. سيظهر زر «أدوات الباحث» في علامة التبويب «الصفحة الرئيسية».
