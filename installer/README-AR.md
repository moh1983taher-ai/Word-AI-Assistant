# الحزمة الموحدة لأدوات الباحث 1.2.12

## مكونات المثبّت

يُنتج خط البناء ملفًا واحدًا باسم `ResearchTools-Setup.exe` لنظام Windows x64. ويجمع:

- محرك DuckAI المحلي وحزمة التشغيل المنشورة والمتحقق من بصمتها.
- مضيف `ResearchTools.McpHost` المستقل ذاتيًا على .NET 10، المبني على SDK الرسمي لـ MCP.
- مشغّل خلفية واحد يدير DuckAI ووكيل الخدمة ومضيف MCP، ويبدأها عند تشغيل Word ويوقفها عند إغلاقه.
- ملف إعداد الإضافة `Word-AI-Assistant.xml` بمعرّف الإضافة الحالي، لعرض زر «أدوات الباحث» داخل شريط Word.
- ملفات الفحص والتحقق من SHA-256، مع الاحتفاظ بنسخة سابقة من المضيف عند التحديث.

## التثبيت

1. أغلق Microsoft Word بالكامل.
2. شغّل `ResearchTools-Setup.exe` من حساب Windows المعتاد.
3. وافق على طلب صلاحية إنشاء مشاركة مجلد الإضافات إذا احتاج الجهاز إلى كتالوج Word جديد.
4. بعد اكتمال التثبيت، افتح Word. سيظهر زر «أدوات الباحث» في علامة التبويب «الصفحة الرئيسية».
5. عند فتح Word، يشغّل المشغّل DuckAI ومضيف MCP تلقائيًا. وتستخدم الإضافة واجهة Word المنشورة على GitHub Pages.

لا يتطلب المضيف تثبيت .NET Runtime منفصلًا؛ فهو مضمّن في الملف التنفيذي المنشور ذاتيًا.

## المسارات والسجلات

- DuckAI: `%LOCALAPPDATA%\ResearchTools\DuckAI`
- MCP Host: `%LOCALAPPDATA%\ResearchTools\McpHost`
- المشغّل: `%LOCALAPPDATA%\ResearchTools\ResearchTools-Launcher.vbs`
- نسخ الاستعادة: `%LOCALAPPDATA%\ResearchTools\Backup`
- سجل التثبيت: `%LOCALAPPDATA%\ResearchTools\Logs\ResearchTools-Setup.log`

تحتفظ الحزمة بمسار توافق احتياطي إلى جسر MCP القديم إذا غاب الملف التنفيذي للمضيف الجديد. ولا تستبدل ملفات التطوير في `C:\Word AI Assistant v2`.

## حدود الحزمة

هذه حزمة تثبيت وتكامل محلية وليست نسخة دون اتصال من واجهة Word؛ إذ تظل لوحة الإضافة وصفحاتها ومواردها مستضافة على GitHub Pages، كما يتطلب البحث اتصالًا بمصادر MCP الخارجية.
