# ResearchTools MCP Host

مضيف «أدوات الباحث» المحلي مبني على .NET 10، ويستخدم حزمة **Model Context Protocol C# SDK** الرسمية إصدار 2.4.0.

## البنية والواجهات

- يستمع المضيف على `127.0.0.1:18081` افتراضياً، ولا يفتح منفذاً على واجهات الشبكة الخارجية.
- يحافظ على واجهات Word المتوافقة: `/ping` و`/health` و`/v1/models` و`/v1/research`.
- يتيح خادماً محلياً قياسياً لـ MCP عبر Streamable HTTP على:
  `http://127.0.0.1:18081/mcp`.
- واجهة `/v1/mcp/sources` تعرض حالة الاتصال وأدوات القراءة المكتشفة، وتتحقق من صلاحية المخطط الموحد الذي يستخدمه مسار التوافق مع DuckAI.
- يتصل بمصدري MCP المحددين في المشروع فقط: الجامع `https://aljam3.com/mcp` والمكتبة الشاملة `https://mcp.shamela.ws`.
- يستخدم عملاء MCP الرسميين مع النقل التلقائي، ويحتفظ بفهرس الأدوات خمس دقائق.
- يعرض خادم MCP المحلي الأدوات بأسماء مميزة مثل `mcp_aljam3__search` و`mcp_shamela__search`، ويحافظ على مخطط معاملات كل أداة. وتظهر الأدوات في الخادم المحلي بعلامات MCP الدلالية التي تصفها بأنها للقراءة فقط؛ لكن الأمان لا يعتمد على هذه العلامات، بل على سياسة السماح المحلية والتحقق من معاملات كل استدعاء.
- خادم MCP المحلي يتيح الأدوات المكتشفة من المكتبتين للعميل المتصل به. أما عند البحث من Word، فإن اختيار المستخدم للجامع أو الشاملة أو كليهما هو الحد الحاسم للأدوات التي يراها النموذج.

## اختيار النموذج وتنفيذ الأدوات

- يفضّل المضيف استدعاءات الوظائف الأصلية المتوافقة مع OpenAI: يرسل النموذج جميع أدوات المكتبات المختارة، ثم ينفّذ المضيف الاستدعاءات التي يعيدها النموذج ويعيد النتائج إليه، بما فيها عدة استدعاءات في دورة واحدة. يقرر النموذج بعد ذلك مواصلة البحث أو إصدار الإجابة.
- إذا رفض مزود DuckAI المحلي استدعاء الوظائف الأصلية أو لم يُرجع استدعاءات أدوات، ينتقل المضيف تلقائياً إلى بروتوكول قرارات JSON الصارم المتوافق مع النسخة المثبتة. وفي هذا المسار أيضاً تكون جميع أدوات المكتبات المختارة متاحة ويُسمح بقرار الإجابة النهائية منذ أول دورة.
- لا يفرض المضيف استخدام كل مكتبة مختارة، ولا يرتب أولوية البحث بينها، ولا يحدد عدد استدعاءات الأدوات. اختيار المكتبات يحدد النطاق المسموح فقط؛ أما اختيار الأداة وتكرار البحث وكفايته وتوقيت إنهائه فهي قرارات النموذج.
- لا يُسمح بأدوات الكتابة أو التعديل أو الحذف. يتحقق المضيف من اسم الأداة ومعاملاتها بمقارنة الاستدعاء مع فهرس MCP المسموح قبل تنفيذه.
- تُحفظ نتائج الأدوات في سجل أدلة مستقل عن اختصار سجل المحادثة، وتُستخدم لتقييد الإحالات والمراجع بما عاد فعلاً من المكتبات المختارة. لا تُنشأ صفحات أو روابط غير موجودة في النتائج.

## حدود التشغيل والحماية

- مهمتا بحث متزامنتان كحد أعلى لحماية خدمة DuckAI المحلية.
- مهلة البحث 300 ثانية. عند انتهائها يتوقف بدء استدعاءات أدوات جديدة، ويحاول المضيف صياغة إجابة جزئية خلال 30 ثانية اعتماداً على الأدلة التي جُمعت، ثم يعرض مقتطفات الأدلة المحفوظة إن تعذر ذلك.
- يحد سياق المحادثة المرسل إلى النموذج بـ20,000 حرف في كل دورة توليد، مع سقف 12,000 حرف للرسالة الواحدة. ويظل طلب المستخدم الأحدث والأدلة ضمن عملية الاختصار؛ ولا يُعد هذا الحد سقفاً لعدد استدعاءات الأدوات.
- فحص الحياة `/ping` مستقل عن مهام البحث الطويلة.
- خادم MCP المحلي مقيّد بـ loopback وHost header مضبوط. لا تُعد واجهة MCP على loopback بديلاً عن المصادقة في حال تغيير نطاق الاستماع مستقبلاً؛ لا تفتحها على شبكة عامة دون إضافة مصادقة وسياسة وصول مناسبة.

## ربط عميل محلي بـ MCP

بعد تشغيل المضيف، استخدم عنوان MCP التالي في عميل يدعم Streamable HTTP:

```text
http://127.0.0.1:18081/mcp
```

يمكن اختبار الاتصال من LM Studio أو أي عميل MCP محلي متوافق. استخدم إعداد اتصال HTTP/Streamable HTTP في العميل، وليس إعداد خادم stdio. يجب أن يكون المضيف وخادما الجامع والشاملة متاحين على الجهاز/الاتصال قبل طلب الأدوات. قد تختلف شاشة الإعداد واسم الحقل بين تطبيق وآخر.

لا يحتاج عميل MCP المحلي إلى Origin متصفح؛ ومع ذلك يقبل المضيف فقط الاتصالات إلى عنوان loopback نفسه والمنفذ المضبوط، ويرفض Origins الخارجية. أما واجهات Word الحالية فتحتفظ بقائمة Origins الموثوقة المنفصلة.

## الاختبار التجريبي على Windows دون المساس بالخدمة الحالية

تحتوي الحزمة على `Start-McpHost-Preview.ps1`. يشغّل المضيف مؤقتاً على المنفذ `18082`، ويختبر DuckAI واكتشاف خادمي MCP وتنفيذ بحث حقيقي وفحص `/ping` أثناء البحث، ثم يغلق العملية التجريبية وحدها. تبقى الخدمة الموجودة على المنفذ `18081` كما هي.

```powershell
.\Start-McpHost-Preview.ps1
```

ولتغيير السؤال أو المكتبات:

```powershell
.\Start-McpHost-Preview.ps1 -Question 'ابحث عن ...' -Servers @('aljam3')
```

يجب أن يتضمن البحث الفعلي استدعاء أداة MCP ناجحاً واحداً على الأقل، وأن تكون كل الاستدعاءات من المكتبات التي حددها الاختبار. لا يشترط استخدام كل مكتبة اختيرت.

## البناء والاختبار

يتطلب .NET 10 SDK:

```powershell
dotnet restore runtime/McpHost.Tests/ResearchTools.McpHost.Tests.csproj
dotnet test runtime/McpHost.Tests/ResearchTools.McpHost.Tests.csproj --configuration Release
dotnet publish runtime/McpHost/ResearchTools.McpHost.csproj --configuration Release --runtime win-x64 --self-contained true -p:PublishSingleFile=true
```

يتحقق GitHub Actions من استعادة الحزم والاختبارات والبناء والنشر الذاتي لـ Windows x64، وصحة سكربتات PowerShell، واكتشاف الأدوات الفعلية من الخادمين upstream.

## ملاحظات التوافق

- واجهة MCP القياسية مضافة بالتوازي مع واجهات REST التي تعتمد عليها إضافة Word؛ لا يتغير عنوان Word أو معرّف الإضافة.
- يظل DuckAI الحالي مدعوماً عبر مسار JSON التوافقي. أما استدعاء الوظائف الأصلي فيُستخدم تلقائياً عندما يقدمه مزود النموذج.
- هذا التغيير فرع تطوير مستقل. لا يستبدل النسخة المثبتة ولا ينشر إصداراً جديداً قبل اجتياز CI واختبار التكامل على Windows.
